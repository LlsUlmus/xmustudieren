# 实验3：黑盒测试用例设计

## 一、被测程序说明

**程序名称：** `BlackBox.java`

**功能描述：** 输入年（year）、月（month）、日（day）三个变量，在输入合法的前提下，计算并输出该日期**隔一日**（即加 2 天）后的日期。

**输入约束：**
- 1900 ≤ year ≤ 2050
- 1 ≤ month ≤ 12
- 1 ≤ day ≤ 31（且须为真实存在的日期）

**输出规则：**
1. 年份不在 [1900, 2050] → 输出「年份不符合要求！」
2. 年份合法但日期不存在 → 输出「该日期不存在！」
3. 日期合法 → 输出「其隔一日日期为：xxxx年xx月xx日」

**示例：** 输入 2021年7月22日 → 输出 2021年7月24日

---

## 二、等价类划分

### 2.1 输入变量等价类

| 变量 | 有效等价类 | 无效等价类 |
|------|-----------|-----------|
| **year** | EC-Y1: [1900, 2050] | EC-Y2: year < 1900；EC-Y3: year > 2050 |
| **month** | EC-M1: [1, 12] | EC-M2: month < 1；EC-M3: month > 12 |
| **day（大月：1,3,5,7,8,10,12）** | EC-D1: [1, 31] | EC-D2: day ≤ 0；EC-D3: day > 31 |
| **day（小月：4,6,9,11）** | EC-D4: [1, 30] | EC-D5: day ≤ 0；EC-D6: day = 31 |
| **day（闰年2月）** | EC-D7: [1, 29] | EC-D8: day ≤ 0；EC-D9: day > 29 |
| **day（平年2月）** | EC-D10: [1, 28] | EC-D11: day ≤ 0；EC-D12: day > 28 |

### 2.2 闰年判定等价类

| 等价类 | 条件 | 示例 |
|--------|------|------|
| EC-L1 闰年 | (year%4==0 && year%100!=0) \|\| year%400==0 | 2000, 2004, 2020 |
| EC-L2 平年 | 不满足闰年条件 | 1900, 2001, 2021 |

### 2.3 日期计算功能等价类

| 等价类 | 描述 |
|--------|------|
| EC-F1 | 同月内 day+2，不跨月 |
| EC-F2 | 小月（30天）月末跨月：day=29→下月1日；day=30→下月2日 |
| EC-F3 | 大月（31天）月末跨月：day=30→下月1日；day=31→下月2日 |
| EC-F4 | 12月跨年到1月：day=30→次年1月1日；day=31→次年1月2日 |
| EC-F5 | 闰年2月跨到3月：day=28→3月1日；day=29→3月2日 |
| EC-F6 | 平年2月跨到3月：day=27→3月1日；day=28→3月2日 |

## 四、决策表设计

### 4.1 条件桩

| 编号 | 条件 | 取值 |
|------|------|------|
| C1 | 年份是否合法（1900≤year≤2050） | Y / N |
| C2 | 日期是否合法 | Y / N |
| C3 | 是否2月 | Y / N |
| C4 | 是否闰年 | Y / N |
| C5 | 是否小月（4,6,9,11） | Y / N |
| C6 | 是否12月 | Y / N |
| C7 | 是否触发跨月/跨年（day接近月末） | Y / N |

### 4.2 动作桩

| 编号 | 动作 |
|------|------|
| A1 | 输出「年份不符合要求！」 |
| A2 | 输出「该日期不存在！」 |
| A3 | 同月 day+2 |
| A4 | 跨月计算（小月 day=29/30） |
| A5 | 跨月计算（大月 day=30/31） |
| A6 | 跨年计算（12月 day=30/31） |
| A7 | 闰年2月跨月（day=28/29） |
| A8 | 平年2月跨月（day=27/28） |

### 4.3 决策规则表

| 规则 | C1 | C2 | C3 | C4 | C5 | C6 | C7 | 动作 |
|------|----|----|----|----|----|----|----|----|
| R1 | N | - | - | - | - | - | - | A1 |
| R2 | Y | N | - | - | - | - | - | A2 |
| R3 | Y | Y | N | - | N | N | N | A3 |
| R4 | Y | Y | N | - | Y | N | Y | A4 |
| R5 | Y | Y | N | - | N | N | Y | A5 |
| R6 | Y | Y | N | - | - | Y | Y | A6 |
| R7 | Y | Y | Y | Y | - | - | Y | A7 |
| R8 | Y | Y | Y | N | - | - | Y | A8 |

> 说明：「-」表示该条件在此规则下不影响决策；C7 为 Y 表示 day 处于需要跨月/跨年的临界值。

## 六、测试执行说明

### 6.1 手工测试（交互式）

```bash
cd blackbox
javac BlackBox.java
java blackbox.BlackBox
```

按提示依次输入 `年 月 日`（空格分隔），观察控制台输出并截图。

**建议截图用例（至少 5 组）：**
1. 正常用例：2021 7 22 → 2021年7月24日
2. 年份非法：1899 1 1 → 年份不符合要求！
3. 日期非法：2021 4 31 → 该日期不存在！
4. 跨年：2021 12 31 → 2022年1月2日
5. 闰年2月：2020 2 29 → 2020年3月2日

### 6.2 自动化批量测试

```bash
cd blackbox
javac BlackBoxTestRunner.java BlackBox.java
java blackbox.BlackBoxTestRunner > test_result.txt
```

将 `test_result.txt` 内容或控制台输出截图作为测试执行证据。
