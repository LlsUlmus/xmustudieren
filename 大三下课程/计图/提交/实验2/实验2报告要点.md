## Task1：Sierpinski镂垫程序

### 1）尝试为不同三角形设置不同颜色，使得看起来更美观

**原理说明：**
Sierpinski镂垫本质是“递归细分三角形”：每次把一个大三角形分成三个小三角形并继续细分。要实现“不同三角形不同颜色”，可以在递归终止时，根据当前小三角形的几何特征（如中心点坐标、到原点距离、递归层级）计算颜色，再调用 `glColor3f` 着色。

**操作步骤：**
1. 编写递归函数 `drawTriangle(...)`，参数包含三个顶点和递归深度。
2. 当 `depth==0` 时执行实际绘制（`GL_TRIANGLES`）。
3. 在终止层中计算每个小三角形中心点 `(cx, cy)`。
4. 将中心点映射到颜色空间（本实验使用 HSV->RGB 转换），得到更平滑的配色。
5. 调整饱和度和明度范围，使颜色层次更明显。

**关键代码截图建议：**
- `drawTriangle(...)` 递归拆分逻辑。
- `HSV2RGB(...)` 颜色转换函数。
- `depth==0` 分支中 `glColor3f(...)` 与 `glVertex2f(...)`。

**运行结果截图建议：**
- 选一帧静态图，显示镂垫中不同区域颜色明显不同。

### 2）为镂垫生成动画（颜色变化 + 旋转 + 缩放）

**原理说明：**
动画通过“每帧更新时间参数 + 重绘场景”实现：
- 颜色变化：让 HSV 中的 H/S/V 随时间函数变化。
- 旋转效果：在模型矩阵中调用 `glRotatef`。
- 缩放效果：在模型矩阵中调用 `glScalef`，缩放因子使用正弦函数周期变化。

**操作步骤：**
1. 在全局定义动画参数：`g_timeSec`、`g_rotDeg`、`g_scale`。
2. 在 `idle()` 中基于 `GLUT_ELAPSED_TIME` 计算 `dt`，更新上述参数。
3. 在 `display()` 中先清屏，再执行 `glRotatef(...)` 与 `glScalef(...)`。
4. 在终止层着色时引入 `g_timeSec`，让颜色随时间变化。
5. 调用 `glutPostRedisplay()` 持续刷新。

**关键代码截图建议：**
- `idle()` 中时间更新与角度/缩放更新语句。
- `display()` 中 `glRotatef(...)`、`glScalef(...)`。

**运行结果截图建议：**
- 颜色变化前后两帧。
- 旋转角度不同的两帧。
- 缩放大小不同的两帧。

## Task2：完成一个三维程序

### 1）设置合适的相机位置和相机投影矩阵

**原理说明：**
三维显示要经过“观察变换 + 投影变换”：
- `GL_MODELVIEW` 阶段主要确定相机与物体的相对位置关系（常用 `gluLookAt`）。
- `GL_PROJECTION` 阶段定义可视体范围（常用 `gluPerspective`/`glOrtho`/`glFrustum`）。

**操作步骤：**
1. 在 `reshape()` 中设置 `glViewport(...)`。
2. 切到 `GL_PROJECTION`，调用 `gluPerspective(fov, aspect, near, far)`。
3. 在 `display()` 中切到 `GL_MODELVIEW` 并 `glLoadIdentity()`。
4. 使用 `gluLookAt(eye, center, up)` 设置相机位置和朝向。
5. 通过调整参数验证视野大小、远近裁剪、观察方向变化。

**关键代码截图建议：**
- `reshape()` 中 `glMatrixMode(GL_PROJECTION)` + `gluPerspective(...)`。
- `display()` 中 `gluLookAt(...)`。

**运行结果截图建议：**
- 两张对比图：调整投影参数前后。
- 两张对比图：调整相机位置/朝向前后。

#### 思考题回答
**a. OpenGL中，三维空间的坐标系是怎么样的？**
答：OpenGL默认采用右手坐标系。通常取 X 轴向右、Y 轴向上，Z 轴方向由右手法则确定。场景中点和向量均在该三维坐标系中表示。

**b. OpenGL中，相机的方位是怎么样的？如何调整相机朝向？**
答：相机方位由“位置（eye）+ 观察目标（center）+ 上方向（up）”共同决定。可以用 `gluLookAt` 直接指定，也可通过 yaw/pitch 计算前向向量，再动态更新 `center=eye+front`。

**c. OpenGL中，相机可见范围是如何设置的？**
答：通过投影矩阵设置。透视投影用 `gluPerspective/glFrustum`（控制视角、宽高比、近远裁剪面），正交投影用 `glOrtho`（控制近平行投影视体范围）。

### 2）对示例程序进行改写

#### a. 比较开启/不开启深度缓冲区 `glEnable(GL_DEPTH_TEST)` 的效果

**原理说明：**
深度缓冲区保存每个像素当前最近片元的深度值。开启深度测试后，绘制新片元时会与缓冲区深度比较，只有更近片元才会更新颜色，从而保证遮挡关系正确。

**操作步骤：**
1. 初始化窗口模式包含 `GLUT_DEPTH`。
2. 在初始化或绘制时开启 `glEnable(GL_DEPTH_TEST)`。
3. 每帧清屏时使用 `glClear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT)`。
4. 增加按键（如 `T`）切换 `GL_DEPTH_TEST` 以对比效果。

**运行结果结论：**
- 开启深度测试：前后遮挡正确。
- 关闭深度测试：后绘制面会错误覆盖前景，出现穿插错乱。

#### b. 让正方体自行旋转，而不是相机旋转

**原理说明：**
把旋转变换施加在物体模型矩阵上，而不是改变 `gluLookAt` 参数；这样相机保持稳定，视觉上是“物体自转”。

**操作步骤：**
1. 在 `idle()` 中持续增加旋转角 `g_cubeRot`。
2. 在 `display()` 中先设置相机，再对立方体执行 `glRotatef(g_cubeRot, ...)`。
3. 通过双轴旋转增强立体感（如 Y 轴 + X 轴）。

#### c. 在正方体自转前提下，实现交互式相机控制

**原理说明：**
- 平移：基于相机前向向量 `front` 与右向量 `right` 进行位移。
- 视角：根据鼠标位移更新 yaw/pitch，再计算新的 `front`。
- 锁定：使用状态变量阻止输入更新。

**操作步骤：**
1. 定义相机状态：`camPos/yaw/pitch`。
2. 键盘 `WASD` 控制前后左右，`QE` 控制升降。
3. 鼠标右键按住时读取 `dx/dy` 更新 yaw/pitch。
4. 按 `L` 切换锁定状态。
5. 每帧根据新相机参数更新 `gluLookAt(...)`。

**关键代码截图建议：**
- 按键状态处理（`keyboardDown/keyboardUp`）。
- `idle()` 中相机位移更新。
- `mouseButton/passiveMotion` 中视角更新。
- `display()` 中 `gluLookAt(...)`。

#### 思考题回答
**如何实现前后面的遮挡？**
答：核心是“深度缓冲 + 深度测试”。实现步骤为：
1. 创建带深度缓冲的窗口：`glutInitDisplayMode(... | GLUT_DEPTH)`；
2. 开启深度测试：`glEnable(GL_DEPTH_TEST)`；
3. 每帧清空颜色和深度：`glClear(GL_COLOR_BUFFER_BIT | GL_DEPTH_BUFFER_BIT)`；
4. 默认比较函数为 `GL_LESS`，较近片元通过并写入深度缓冲，较远片元被丢弃，因此前景会正确遮挡背景。

## Task3：绘制线框球体

### 1）在不使用glut对象函数的情况下绘制线框球体

**原理说明：**
使用球面参数方程：
- `x = r cos(v) cos(u)`
- `y = r sin(v)`
- `z = r cos(v) sin(u)`
通过遍历纬度/经度采样点并用线段连接，形成线框球。

**操作步骤：**
1. 编写 `drawWireSphere(radius, stacks, slices)`。
2. 纬线使用 `GL_LINE_LOOP`。
3. 经线使用 `GL_LINE_STRIP`。
4. 验证代码中未调用 `glutWireSphere`。

### 2）添加动画效果，让球体绕圆心旋转

**原理说明：**
与Task2类似，在 `idle()` 累加旋转角，在 `display()` 中对球体执行旋转变换。

**操作步骤：**
1. 增加全局角度 `g_spinDeg`。
2. `idle()` 中递增角度并触发重绘。
3. `display()` 中 `glRotatef(g_spinDeg, ...)`。

### 3）添加reshape回调，保持比例不形变

**原理说明：**
窗口宽高变化会改变纵横比，需在 `reshape()` 中更新 `glViewport` 与投影矩阵宽高比，避免对象拉伸。

**操作步骤：**
1. 在 `reshape(w,h)` 中保证 `h != 0`。
2. 调用 `glViewport(0,0,w,h)`。
3. 调用 `gluPerspective(fov, (double)w/h, near, far)`。

### 4）添加交互式相机控制（同Task2）

**原理说明：**
复用Task2的相机控制模型，保持操作一致性，便于实验对比。

**操作步骤：**
1. 引入 `camPos/yaw/pitch`。
2. 实现 `WASDQE` 位移。
3. 实现鼠标控制朝向。
4. 实现 `L` 锁定状态。

**关键代码截图建议：**
- `drawWireSphere(...)` 参数化绘制代码。
- `idle()` 旋转更新。
- `reshape(...)` 宽高比处理。
- 相机控制函数（键盘/鼠标）。
