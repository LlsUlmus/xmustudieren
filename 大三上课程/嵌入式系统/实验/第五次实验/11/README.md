# 嵌入式设备控制程序说明

本文档说明四个嵌入式设备控制程序的主要功能和代码结构。

## 1. ir_buzzer - 红外遥控器与蜂鸣器控制

### 主要功能
- 读取红外遥控器的输入事件（通过 `/dev/input/event0` 设备）
- 识别遥控器按键（开关、音量、方向键、数字键等）
- 当按下数字键"1"时，切换蜂鸣器的开关状态
- 蜂鸣器通过 `/dev/buzzer_ctl` 设备控制

### 代码说明
- **设备初始化**：打开红外设备文件和蜂鸣器设备文件
- **事件循环**：持续读取红外输入事件，解析按键码
- **按键处理**：使用 `switch-case` 结构处理不同按键码
- **蜂鸣器控制**：使用 `ioctl` 系统调用控制蜂鸣器开关
- **优化改进**：
  - 去除重复的头文件包含
  - 改进错误处理，添加资源清理
  - 简化蜂鸣器状态切换逻辑（使用 `!` 运算符）

---

## 2. keys_gpio_leds - 按键与LED控制

### 主要功能
- 读取物理按键输入（通过 `/dev/farsight_keys` 设备）
- 控制两个LED灯的开关状态（通过 `/dev/leds_ctl` 设备）
- 按键1控制LED1的开关，按键2控制LED2的开关
- 实现按键的按下/释放检测

### 代码说明
- **设备初始化**：打开按键设备和LED设备
- **LED初始化**：启动时关闭所有LED
- **按键读取**：读取按键缓冲区，包含按键编号和状态（按下/释放）
- **LED控制**：使用 `ioctl` 系统调用控制LED的开关
- **优化改进**：
  - 去除重复的头文件包含
  - 简化LED状态切换逻辑
  - 改进代码可读性和错误处理

---

## 3. zlg72xx_lm75 - LM75温度传感器与显示

### 主要功能
- 读取LM75温度传感器的数据（通过 `/dev/temp` 设备）
- 将温度值转换为摄氏度
- 在ZLG72xx显示设备上显示温度值（通过 `/dev/zlg72xx` 设备）
- 每5秒更新一次温度显示

### 代码说明
- **温度计算**：LM75传感器数据格式为 `温度 = 0.125 * (data >> 5)`
- **数据转换**：
  - `int_to_char()`: 将数字转换为字符（0-9）
  - `int_to_char_dot()`: 将数字转换为带小数点的字符（G-P对应0-9）
- **显示格式**：温度值格式化为 "XX.X" 格式显示
- **优化改进**：
  - 简化温度计算逻辑，使用更直观的方法提取整数和小数部分
  - 移除测试代码和硬编码值
  - 改进错误处理和代码注释

## 4. zlg72xx_stepper - 步进电机控制

### 主要功能
- 通过按键控制步进电机的旋转方向
- 支持顺时针和逆时针两种旋转方向
- 使用多线程实现步进电机的控制
- 按键"1"控制顺时针旋转，按键"2"控制逆时针旋转
- 再次按下相同按键可停止电机

### 代码说明
- **步进电机原理**：使用8拍控制序列，通过4个线圈的不同组合实现旋转
- **线程设计**：
  - `stepper_clockwise()`: 顺时针旋转控制线程
  - `stepper_anticlockwise()`: 逆时针旋转控制线程
- **控制序列**：使用数组存储8拍控制序列，简化代码
- **按键处理**：通过 `ioctl` 读取按键值，切换电机运行状态
- **优化改进**：
  - 去除重复的头文件包含
  - 使用数组存储步进序列，减少代码重复
  - 改进变量声明（使用 `volatile` 关键字保护共享变量）
  - 添加线程休眠机制，减少CPU占用

## 通用优化说明

所有程序都进行了以下最小优化：

1. **头文件清理**：去除重复和未使用的头文件包含
2. **错误处理**：改进设备打开失败时的错误处理和资源清理
3. **代码风格**：统一代码格式，提高可读性
4. **变量类型**：使用 `ssize_t` 等更合适的类型
5. **逻辑简化**：使用更简洁的表达式（如 `!` 运算符）替代 if-else

## 编译说明

这些程序需要在支持相应设备驱动的Linux系统上编译运行，通常需要：
- Linux内核支持相应的设备驱动
- 设备文件存在于 `/dev/` 目录下
- 使用 `gcc` 编译，可能需要链接 `pthread` 库（步进电机程序）

示例编译命令：
```bash
gcc ir_buzzer.c -o ir_buzzer
gcc keys_gpio_leds.c -o keys_gpio_leds
gcc zlg72xx_lm75.c -o zlg72xx_lm75
gcc zlg72xx_stepper.c -o zlg72xx_stepper -lpthread
```
