# 设计实验4-2：通过图标控制蜂鸣器 - 实验思路

## 实验要求
将第7次实验的Android蜂鸣器实验（原本通过按钮START、STOP控制蜂鸣器的响/不响）修改为通过图标控制蜂鸣器的响/不响。蜂鸣器响的时候显示一个图标，蜂鸣器不响的时候显示另一个图标。

## 实验工程命名
**Buzzer_Icon**

## 编程思路

### 一、参考LED实验的实现方式

#### 1. LED实验的关键实现特点
- 使用`ImageButton`控件替代普通`Button`
- 通过状态标志位（`IsLight_1_On`、`IsLight_2_On`）记录当前状态
- 点击图标时切换状态，同时动态更换`ImageButton`的背景图片：
  - 亮状态：`pic_bulbon.gif`
  - 灭状态：`pic_bulboff.gif`

#### 2. LED实验的核心代码逻辑
```java
// LED实验中的关键代码片段
ImageButton LedButton_1 = (ImageButton)findViewById(R.id.buttonOne);
LedButton_1.setOnClickListener(new View.OnClickListener() {
    @Override
    public void onClick(View view) {
        if (IsLight_1_On) {
            // 当前是亮状态，切换到灭状态
            ((ImageButton)view).setBackground(getDrawable(R.drawable.pic_bulboff));
            led.open();
            led.LedOff1();
            led.close();
        } else {
            // 当前是灭状态，切换到亮状态
            ((ImageButton)view).setBackground(getDrawable(R.drawable.pic_bulbon));
            led.open();
            led.LedOn1();
            led.close();
        }
        IsLight_1_On = !IsLight_1_On; // 切换状态标志
    }
});
```

### 二、蜂鸣器实验的改造方案

#### 1. 界面布局改造（activity_main.xml）

**原实现：**
- 使用两个`Button`控件：`button1`（START）和`button2`（STOP）
- 采用垂直LinearLayout布局

**改造方案：**
- 将两个`Button`替换为一个`ImageButton`
- 使用`ImageButton`显示蜂鸣器状态图标
- 参考LED实验的布局方式，使用ConstraintLayout或RelativeLayout进行布局

**示例代码：**
```xml
<ImageButton
    android:id="@+id/buzzerIcon"
    android:layout_width="wrap_content"
    android:layout_height="wrap_content"
    android:layout_gravity="center"
    android:background="@drawable/buzzer_off"
    android:contentDescription="蜂鸣器控制图标" />
```

#### 2. 图标资源准备（res/drawable）

**需要准备两个图标：**
- `buzzer_on.gif` 或 `buzzer_on.png`：蜂鸣器响时的图标（建议使用带声音波纹的喇叭图标）
- `buzzer_off.gif` 或 `buzzer_off.png`：蜂鸣器不响时的图标（建议使用普通喇叭图标）

**图标建议：**
- 参考图片描述中的示例：响时图标有声音波纹，不响时图标无声音波纹
- 图标尺寸建议：64x64dp 或 128x128dp
- 格式：PNG（透明背景）或GIF

#### 3. Java代码改造（MainActivity.java）

**原实现逻辑：**
- 使用两个按钮分别控制启动和停止
- `button1`点击时调用`buzzer.BuzzerOn()`
- `button2`点击时调用`buzzer.BuzzerOff()`

**改造方案：**
- 使用一个`ImageButton`，通过点击切换状态
- 添加状态标志位`isBuzzerOn`（boolean类型）
- 根据当前状态切换图标和控制蜂鸣器

**核心代码逻辑：**
```java
public class MainActivity extends AppCompatActivity {
    Buzzer buzzer = new Buzzer();
    private ImageButton buzzerIcon;
    boolean isBuzzerOn = false; // 状态标志位，false表示蜂鸣器不响
    
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);
        
        buzzerIcon = (ImageButton) findViewById(R.id.buzzerIcon);
        // 初始状态设置为不响（显示不响图标）
        buzzerIcon.setBackground(getDrawable(R.drawable.buzzer_off));
        
        buzzerIcon.setOnClickListener(new View.OnClickListener() {
            @Override
            public void onClick(View view) {
                if (isBuzzerOn) {
                    // 当前是响的状态，切换到不响
                    ((ImageButton)view).setBackground(getDrawable(R.drawable.buzzer_off));
                    if (buzzer.open() == -1) {
                        Toast.makeText(MainActivity.this, "设备打开失败！", Toast.LENGTH_SHORT).show();
                        return;
                    }
                    buzzer.BuzzerOff();
                    buzzer.close();
                } else {
                    // 当前是不响的状态，切换到响
                    ((ImageButton)view).setBackground(getDrawable(R.drawable.buzzer_on));
                    if (buzzer.open() == -1) {
                        Toast.makeText(MainActivity.this, "设备打开失败！", Toast.LENGTH_SHORT).show();
                        return;
                    }
                    buzzer.BuzzerOn();
                    buzzer.close();
                }
                isBuzzerOn = !isBuzzerOn; // 切换状态标志
            }
        });
    }
}
```

#### 4. Buzzer.java类（保持不变）
`Buzzer.java`类的代码不需要修改，继续使用现有的`open()`、`close()`、`BuzzerOn()`、`BuzzerOff()`方法。

### 三、实现步骤

1. **复制Buzzer项目**
   - 将原有的Buzzer项目复制并重命名为`Buzzer_Icon`

2. **准备图标资源**
   - 创建或下载两个蜂鸣器图标（响/不响）
   - 将图标文件放入`app/src/main/res/drawable/`目录
   - 命名为`buzzer_on.png`和`buzzer_off.png`（或使用gif格式）

3. **修改布局文件**
   - 打开`activity_main.xml`
   - 删除原有的两个Button控件
   - 添加一个ImageButton控件
   - 设置初始背景为`buzzer_off`

4. **修改MainActivity.java**
   - 将`Button`类型改为`ImageButton`
   - 添加状态标志位`isBuzzerOn`
   - 修改`onClick`方法，实现状态切换逻辑
   - 根据状态切换图标背景

5. **测试验证**
   - 编译运行程序
   - 点击图标，验证蜂鸣器能够响/不响切换
   - 验证图标能够正确显示对应的状态

### 四、关键点总结

1. **控件替换**：`Button` → `ImageButton`
2. **控制方式**：两个按钮 → 一个图标按钮（切换模式）
3. **状态管理**：使用boolean标志位记录当前状态
4. **图标切换**：使用`setBackground()`方法动态更换图标
5. **参考实现**：LED实验是很好的参考模板

### 五、与LED实验的对比

| 对比项 | LED实验 | Buzzer实验（改造后） |
|--------|---------|---------------------|
| 控件类型 | ImageButton | ImageButton |
| 状态数量 | 2个（亮/灭） | 2个（响/不响） |
| 图标数量 | 2个（pic_bulbon/pic_bulboff） | 2个（buzzer_on/buzzer_off） |
| 控制方法 | LedOn1()/LedOff1() | BuzzerOn()/BuzzerOff() |
| 实现逻辑 | 点击切换状态和图标 | 点击切换状态和图标（相同） |

### 六、注意事项

1. 确保图标文件格式正确，建议使用PNG格式并放置在正确的drawable文件夹中
2. 初始化时图标应显示为不响状态（buzzer_off）
3. 设备打开失败时要显示提示信息，并保持图标状态不变
4. 每次操作后都要调用`buzzer.close()`关闭设备
5. 图标要有良好的视觉效果，能够清晰区分响/不响两种状态
