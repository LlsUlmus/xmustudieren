## 快速复制路径方法

### Windows系统
1. 在文件资源管理器中导航到对应目录
2. 按住Shift键，右键点击文件
3. 选择"复制为路径"
4. 粘贴到文档中

### VS Code
1. 右键点击文件
2. 选择"Copy Path"或"Copy Relative Path"

## 注意事项

1. **文件路径中的空格**：路径中包含空格（如"Android实验源代码——Application"），复制时注意引号
2. **文件编码**：确保文件以UTF-8编码打开，避免中文乱码
3. **截图范围**：建议截图包含：
   - 文件路径栏（显示完整路径）
   - 代码内容（关键方法或完整类）
   - 行号（方便引用）
4. **文件大小**：如果文件较大，可以分段截图，标注行号范围

## 文件验证

如果文件路径不存在，请检查：
1. 项目是否在指定位置
2. 文件夹名称是否正确（注意中英文和特殊字符）
3. 文件是否被移动或重命名

可以使用以下命令在PowerShell中验证文件是否存在：
```powershell
Test-Path "文件路径"
```
