==========================================
1. 结构化英语描述（Structured English）
==========================================

IF 年龄 < 20 THEN
    IF 文化程度 = 初中 THEN
        新工作 = 脱产学习
    ELSE IF 文化程度 = 高中 THEN
        新工作 = 电工
    END IF
ELSE IF 年龄 >= 20 AND 年龄 <= 40 THEN
    IF 文化程度 = 中学 THEN
        IF 性别 = 男性 THEN
            新工作 = 钳工
        ELSE IF 性别 = 女性 THEN
            新工作 = 车工
        END IF
    ELSE IF 文化程度 = 大学 THEN
        新工作 = 技术员
    END IF
ELSE IF 年龄 > 40 THEN
    IF 文化程度 = 中学 THEN
        新工作 = 材料员
    ELSE IF 文化程度 = 大学 THEN
        新工作 = 技术员
    END IF
END IF

==========================================
2. 判定表（Decision Table）
==========================================

【表格形式 - 可直接复制到Word或Excel】

| 条件/规则 | 规则1 | 规则2 | 规则3 | 规则4 | 规则5 | 规则6 |
|---------|------|------|------|------|------|------|
| 年龄 < 20 | Y | Y | N | N | N | N |
| 年龄 20-40 | N | N | Y | Y | N | N |
| 年龄 > 40 | N | N | N | N | Y | Y |
| 文化程度 = 初中 | Y | N | N | N | N | N |
| 文化程度 = 高中 | N | Y | N | N | N | N |
| 文化程度 = 中学 | N | N | Y | N | Y | N |
| 文化程度 = 大学 | N | N | N | Y | N | Y |
| 性别 = 男性 | - | - | Y | - | - | - |
| 性别 = 女性 | - | - | N | - | - | - |
| **动作** | | | | | | |
| 新工作 = 脱产学习 | Y | N | N | N | N | N |
| 新工作 = 电工 | N | Y | N | N | N | N |
| 新工作 = 钳工 | N | N | Y | N | N | N |
| 新工作 = 车工 | N | N | N | N | N | N |
| 新工作 = 技术员 | N | N | N | Y | N | Y |
| 新工作 = 材料员 | N | N | N | N | Y | N |

说明：Y=是，N=否，-=不适用

【Mermaid格式 - 可生成表格图形】

注意：Mermaid主要用于流程图，判定表建议直接使用表格格式或Word表格。

【PlantUML活动图格式 - 可生成判定流程】

@startuml
skinparam defaultFontSize 12
skinparam activity {
    BackgroundColor #E8F4F8
    BorderColor #4A90E2
    FontSize 12
}

title 职工重新分配工作判定流程

start
:输入职工信息\n(年龄、文化程度、性别);

if (年龄 < 20?) then (是)
  if (文化程度 = 初中?) then (是)
    :新工作 = 脱产学习;
    stop
  else (否 - 高中)
    :新工作 = 电工;
    stop
  endif
elseif (年龄 20-40?) then (是)
  if (文化程度 = 中学?) then (是)
    if (性别 = 男性?) then (是)
      :新工作 = 钳工;
      stop
    else (否 - 女性)
      :新工作 = 车工;
      stop
    endif
  else (否 - 大学)
    :新工作 = 技术员;
    stop
  endif
else (否 - 年龄 > 40)
  if (文化程度 = 中学?) then (是)
    :新工作 = 材料员;
    stop
  else (否 - 大学)
    :新工作 = 技术员;
    stop
  endif
endif

@enduml

==========================================
【使用说明】
==========================================

1. **结构化英语**：
   - 可以直接复制文本格式到Word文档
   - 保持IF-ELSE IF-THEN的缩进格式

2. **判定表**：
   - 表格格式：可直接复制到Word或Excel
   - PlantUML格式：访问 http://www.plantuml.com/plantuml/uml/ 生成图形

3. **判定树**：
   - PlantUML格式：访问 http://www.plantuml.com/plantuml/uml/ 生成活动图形式的判定树
   - Mermaid格式：访问 https://mermaid.live/ 生成流程图形式的判定树
   - 文本格式：可直接复制到文档中

4. **推荐使用顺序**：
   - 结构化英语：用于理解逻辑流程
   - 判定表：用于展示所有条件组合
   - 判定树：用于可视化决策过程

==========================================
【示例：如何在Word中插入】
==========================================

1. 结构化英语：直接复制文本，使用等宽字体（如Courier New）
2. 判定表：复制表格格式，在Word中插入表格后粘贴
3. 判定树：
   - 方法1：使用PlantUML或Mermaid生成图片后插入
   - 方法2：使用Word的SmartArt图形手动绘制
   - 方法3：直接使用文本格式的判定树
