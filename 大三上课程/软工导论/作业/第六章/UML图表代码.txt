  -申请ID: String
  -申请人: String
  -申请时间: Date

  +更新状态(): void

  -内容: String
  -发送时间: Date

B.2.1 活动图1 - 用户登录流程（Activity Diagram）
==========================================

@startuml
start
:用户打开登录页面;
:输入用户名和密码;
:点击登录按钮;
if (验证用户名和密码?) then (正确)
  :验证成功;
  :跳转到主页面;
  :记录登录日志;
  stop
else (错误)
  :显示错误提示;
  if (错误次数 < 3?) then (是)
    :返回登录页面;
    :允许重新输入;
  else (否)
    :锁定账户;
    :通知管理员;
    stop
  endif
endif
@enduml

==========================================
B.2.1 活动图2 - 申请审核流程（Activity Diagram）
==========================================

@startuml
start
:用户提交申请;
:系统保存申请信息;
:发送通知给管理员;
:管理员登录系统;
:查看待审核申请列表;
:选择申请进行审核;
if (申请信息完整?) then (是)
  if (符合审核条件?) then (是)
    :批准申请;
    :更新申请状态为"已批准";
    :发送通知给申请人;
    stop
  else (否)
    :拒绝申请;
    :更新申请状态为"已拒绝";
    :发送通知给申请人;
    stop
  endif
else (否)
  :退回申请;
  :更新申请状态为"待补充";
  :发送通知给申请人;
  stop
endif
@enduml

B.2.2 数据流图 - 顶层图（Data Flow Diagram - Level 0）
==========================================

@startuml
skinparam componentStyle rectangle

rectangle "系统名称" as System {
  [用户管理] as UserMgt
  [业务处理] as Business
  [数据查询] as Query
  [报表生成] as Report
}

actor 用户 as User
actor 管理员 as Admin
database "数据库" as DB

User --> UserMgt : 用户信息
User --> Business : 业务请求
Admin --> Business : 审核操作
Admin --> Query : 查询请求
Admin --> Report : 报表请求

UserMgt --> DB : 读写用户数据
Business --> DB : 读写业务数据
Query --> DB : 读取数据
Report --> DB : 读取数据

DB --> UserMgt : 用户数据
DB --> Business : 业务数据
DB --> Query : 查询结果
DB --> Report : 统计数据

@enduml

  初审 --> 复审 : 需要复审
  复审 --> [*]

@enduml

==========================================
B.2.4 事件序列图 - 用户登录序列（Sequence Diagram）
==========================================

@startuml
actor 用户 as User
participant "登录界面" as LoginUI
participant "验证服务" as AuthService
participant "用户数据库" as UserDB
participant "日志系统" as LogSystem

User -> LoginUI : 输入用户名和密码
User -> LoginUI : 点击登录按钮
LoginUI -> AuthService : 发送登录请求(用户名,密码)
AuthService -> UserDB : 查询用户信息(用户名)
UserDB --> AuthService : 返回用户信息
AuthService -> AuthService : 验证密码
alt 密码正确
  AuthService -> LogSystem : 记录登录日志
  AuthService --> LoginUI : 返回登录成功
  LoginUI -> LoginUI : 跳转到主页面
  LoginUI --> User : 显示主页面
else 密码错误
  AuthService --> LoginUI : 返回登录失败
  LoginUI --> User : 显示错误提示
end

@enduml

    Admin[管理员] --> Login
    Admin --> Audit[审核申请]
    Admin --> Manage[管理用户]

【类图 - Mermaid】
classDiagram
    class 用户 {
        -String 用户ID
        -String 用户名
        -String 密码
        +登录()
        +注销()
    }
    class 申请 {
        -String 申请ID
        -String 状态
        +提交()
        +查询()
    }
    用户 "1" --> "*" 申请

【活动图 - Mermaid】
flowchart TD
    Start([开始]) --> Input[输入用户名密码]
    Input --> Check{验证}
    Check -->|正确| Success[登录成功]
    Check -->|错误| Error[显示错误]
    Success --> End([结束])
    Error --> Input

【序列图 - Mermaid】
sequenceDiagram
    participant U as 用户
    participant L as 登录界面
    participant A as 验证服务
    U->>L: 输入用户名密码
    L->>A: 发送登录请求
    A->>A: 验证密码
    A-->>L: 返回结果
    L-->>U: 显示结果

==========================================
【使用说明】
==========================================

1. PlantUML代码使用：
   - 访问 http://www.plantuml.com/plantuml/uml/
   - 将@startuml到@enduml之间的代码复制粘贴
   - 点击"Submit"或自动生成图形
   - 右键图片可保存为PNG或SVG格式

2. Mermaid代码使用：
   - 访问 https://mermaid.live/
   - 将代码复制到左侧编辑区
   - 右侧自动显示图形
   - 可导出为PNG、SVG等格式

3. 根据实际项目修改：
   - 将示例中的"系统名称"、"用户"、"管理员"等替换为实际项目中的名称
   - 根据实际业务流程调整活动图和序列图
   - 根据实际数据模型调整类图和数据流图
