B.2.1 活动图1 - 商户开户审核流程（Activity Diagram）
==========================================

@startuml
start
:商户填写开户申请信息;
:提交开户申请;
:系统保存申请信息;
:系统发送通知给管理员;
:管理员登录系统;
:管理员查看待审核申请列表;
:选择商户开户申请;
:查看申请详细信息;
if (申请信息完整?) then (是)
  if (资质证明齐全?) then (是)
    if (符合平台要求?) then (是)
      :管理员批准申请;
      :更新商户状态为"已通过";
      :创建商户账户;
      :发送通知给商户;
      :记录审核日志;
      stop
    else (否)
      :管理员拒绝申请;
      :更新申请状态为"已拒绝";
      :填写拒绝原因;
      :发送通知给商户;
      stop
    endif
  else (否)
    :管理员退回申请;
    :更新申请状态为"待补充";
    :填写补充材料要求;
    :发送通知给商户;
    stop
  endif
else (否)
  :管理员退回申请;
  :更新申请状态为"待补充";
  :填写补充材料要求;
  :发送通知给商户;
  stop
endif
@enduml

    endif

    :支付失败;

    endif
  endif
else (否)
  :订单保持"待支付"状态;
  if (30分钟内未支付?) then (是)
    :系统自动取消订单;

B.2.4 事件序列图 - 顾客下单支付流程（Sequence Diagram）
==========================================

@startuml
actor 顾客 as Customer
participant "商品页面" as ProductPage
participant "订单服务" as OrderService
participant "库存服务" as InventoryService
participant "支付服务" as PaymentService
participant "支付系统" as PaymentSystem
participant "通知服务" as NotifyService
database "数据库" as DB

Customer -> ProductPage : 选择商品，点击购买
ProductPage -> OrderService : 创建订单请求(商品ID,数量,用户ID)
OrderService -> InventoryService : 检查库存(商品ID,数量)
InventoryService -> DB : 查询商品库存
DB --> InventoryService : 返回库存信息
InventoryService --> OrderService : 库存充足

OrderService -> DB : 创建订单记录
DB --> OrderService : 返回订单号
OrderService -> InventoryService : 扣减库存(商品ID,数量)
InventoryService -> DB : 更新库存
InventoryService --> OrderService : 扣减成功

OrderService --> ProductPage : 返回订单信息
ProductPage --> Customer : 显示订单确认页面

Customer -> ProductPage : 确认订单，选择支付方式
ProductPage -> PaymentService : 发起支付请求(订单号,金额,支付方式)
PaymentService -> PaymentSystem : 调用支付接口(订单信息)
PaymentSystem --> PaymentService : 返回支付结果

alt 支付成功
  PaymentService -> OrderService : 更新订单状态(订单号,已支付)
  OrderService -> DB : 更新订单状态
  OrderService -> NotifyService : 发送支付成功通知(商户ID)
  NotifyService -> DB : 保存通知记录
  PaymentService --> ProductPage : 返回支付成功
  ProductPage --> Customer : 显示支付成功页面
else 支付失败
  PaymentService --> ProductPage : 返回支付失败
  ProductPage --> Customer : 显示支付失败提示
end

@enduml
