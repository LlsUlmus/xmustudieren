贪吃蛇游戏使用说明

运行要求：
- Windows 10/11
- .NET 8.0 Runtime（如果系统未安装，请从微软官网下载）

运行方法：
1. 双击 SnakeGame.exe 启动游戏
2. 点击"开始游戏"按钮开始游戏
3. 使用方向键（↑↓←→）控制蛇的移动方向
4. 点击"暂停游戏"可以暂停/恢复游戏
5. 点击"重置游戏"可以重新开始游戏

游戏规则：
- 控制绿色的蛇移动
- 吃到红色的食物可以得分和增长身体
- 撞到墙壁或自己的身体游戏结束
- 每吃一个食物得10分

注意事项：
- 确保所有dll文件都在同一目录下
- 如果无法运行，请检查是否安装了.NET 8.0 Runtime
- 建议在Windows 10或更高版本的系统上运行

技术支持：
如有问题请联系开发者或查看源代码进行调试。
